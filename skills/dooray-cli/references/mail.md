# mail

## 원본 선택과 답장 확인

메일 웹 주소와 mail id 는 도착 시각으로 원본을 추정하므로 다른 메일이 선택될 수 있다.
답장은 UID 직접 입력을 포함한 세 입력 형식 모두 발송 전에 제목, 발신자, 도착 시각과 UID 를 확인하며 기본값은 아니오다.
자동화에서 답장하려면 원본이 맞는지 확인한 뒤 `-y` 또는 `--yes` 를 명시한다.
비대화형 환경에서 이 옵션이 없으면 전송 전에 종료 코드 3으로 중단한다.

## 첨부 저장

`dooray mail get` 이 첨부 목록을 1부터 시작하는 순번과 함께 보여 준다. `--json` 은 `attachments` 배열을 준다.
각 항목은 `index`, `fileName`, `size`, `contentType`, `inline` 이다.
`dooray mail attachment` 의 `--id` 는 이 순번이다. 여러 번 줄 수 있고, 주지 않으면 모두 저장한다.

저장 자리에 같은 이름의 파일이 있으면 그 첨부는 실패하고 종료 코드 1로 끝난다. 덮어쓰려면 `--force` 를 준다.
한 메일 안에서 이름이 겹치면 두 번째부터 `<이름>-<순번><확장자>` 로 저장한다.
없는 순번을 주면 파일을 쓰기 전에 종료 코드 3으로 중단한다.

메일 웹 주소와 mail id 는 도착 시각으로 원본을 추정하므로 다른 메일이 선택될 수 있다.
첨부 저장은 확인을 묻지 않고, 어느 메일에서 받았는지(제목과 UID)를 stderr 에 한 줄로 알린다.
자동화에서는 그 줄이 의도한 메일인지 확인한다.
